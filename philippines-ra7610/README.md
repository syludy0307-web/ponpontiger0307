### 顔出し素材の差し替え方法

`lib/facecam.js` の冒頭コメントに手順を記載。要点は
1. `assets/facecam.mp4` をフレーム連番へ展開
2. `FACECAM.hasFootage = true` にする
3. `drawFootage()` に該当フレームの `drawImage` を書く

呼び出し側（`render.html` の各シーン）は**一切変更不要**。VTR全体を作り直す必要はない。
現状は指示書§5の許可どおり、暗いフィリピン街並み＋法廷＋シルエットで仮置きしている
（AI生成の偽人物は使用していない）。

## 効果音（13種・54キュー）

既存3種（鉄琴/アシカ/ボヨン）に加え、本作用に**7種を合成**：
`whoosh` / `riser` / `scratch`（record scratch）/ `gavel`（木槌）/ `stamp` / `tick` / `paper`
＋既存の `thump`（low boom）・`shutter`・`shatter`。
いずれもピーク実測値からゲインを決め、ナレーションより大きくならないよう -10dB 前後に調整。

## BGM（§15：1段変更）

- セクションA（0–16.02）：HPF220/LPF2800 でこもらせた軽い緊張感・-19.5dB
- **黒0.23秒：完全停止**
- セクションB（16.25–）：フルバンド・-16.5dB＋区間オートメーション
  - 「10日」(33.85–34.55) で一瞬落とす／「意図」区間は 0.52 倍で静かに／オチは 1.45 倍

## 法的な正確性のためのガード（§12）

- 「1回なら合法」という表現は**一切していない**
- 「繰り返せば必ずRA7610」「自動的に有罪」を示すチェックマークも**付けていない**
- Bongalon は「尊厳を貶める特定の意図が合理的疑いを超えて立証されなかった」方向で表現
- 補助字幕として `※内容・状況等により判断されます` `※成立は行為・状況・意図など個別事情で判断` を表示
- エンドカードに出典と「個別のケースは現地の弁護士にご確認ください」を明記
