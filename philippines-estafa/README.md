# エスタファ（刑法315条）ショート（54.5秒 / 1080x1920 / 30fps）

「彼女に送った金は取り返せるのか」— エスタファ（詐欺罪）の成立要件解説。シリーズ8本目。
**抑制演出版**：台本の演出ルールを厳守。

## 演出ルール（台本指定）

- 前半（〜27.9秒）は**金色を一切使わない**（プログレスバーも白に変更）。最初の金は【6】の金チェック
- 要件②「金が動く前」を**強調しない**（色・サイズ・効果音を①③④と完全に同一に）
- **赤フラッシュは42.2秒の1回だけ／低音のドンは43.3秒の1回だけ**
- 紙吹雪・集中線・ボヨンは不使用。カット切替はシャッター音

## セクション構成

1. 【1】0-2.9秒 … 黒背景に送金明細がスライドイン、「取り返せるのか」静かに置く
2. 【2】2.9-8秒 … 4ハードカット：エスタファ特大 → 刑法315条判子（白）→ 詐欺罪 → 空の時系列バー
3. 【3-5】8-21秒 … チェックボックス4つ（0.3秒間隔ポップ）→ 順にチェック（全部同じ扱い）→ 4つ揃って白く一瞬光る
4. 【6-7】21-36秒 … カード3枚スナップ→裏返って「最初から存在しない」→バー左へ束＋**金✓** ／ 3枚→バー右へ束＋赤✖
5. 【8】36-39秒 … 上下比較＋同じ₱300,000＋通る側だけ金グロー
6. 【9】39-47秒 … チェック再登場→①③④が順に暗転→**赤フラッシュ→無音1秒→低音ドン**→②だけ中央へ→「タイミング」赤スタンプ
7. 【10】47-54秒 … ハートが静かに消える（✖なし）→ 嘘（赤）と送金（白）の2点が入れ替わるアニメ1往復 → 「どっちが先か、それだけだ。」金スケールポップ → 暗転
