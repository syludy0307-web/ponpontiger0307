# 名義を借りた土地は戻らないショート（60秒 / 1080x1920 / 30fps）

Frenzel v. Catito（G.R. No. 143958, 2003）とアンチダミー法（CA 108）の解説。シリーズ7本目。
ストーリー型フック（4カット・ハードカット）＋台本の演出指定をフル実装。

## ビルド手順

```bash
NODE_PATH=/opt/node22/lib/node_modules node capture.cjs   # → out/video_silent.mp4
node mix.cjs   # → out/philippines_land_final.mp4 + philippines_land_tiktok.mp4
```

## セクション構成

1. ストーリー（0-18.6秒）… **4カットのハードカット**（①ネオン店内グラス2つ ②夕暮れの家と2人 ③契約書に判子・名義は彼女だけ ④夜の家に1人）カットごとにシャッター音、**カット④でBGM1秒無音→低音のドン** → 「一円も戻らない」赤特大
2. 判例（18.6-31.8秒）… 「実話」赤特大 → 2003年最高裁（実写パネル）→ 判決文に**NULL AND VOIDスタンプ**（着地でカメラ揺れ＋紙が舞う）→ 「土地」「払った金」を赤✖で潰す
3. 騙されたは効かない（31.8-42.5秒）… 吹き出し「騙された」を✖で割る → 隠されていた夫💍 → 「それでも、負けた」→ **天秤が水平で止まる**（同罪、金フラッシュ）
4. 逆転（42.5-53.9秒）… 「訴える＝自白」→ 訴状を差し出す手に**手錠が閉じる**（閉じる音＋赤1フレーム）→ アンチダミー法 → 懲役5年→15年カウントアップ → 「強制送還」
5. オチ（53.9-60秒）… 土地登記簿（所有者：彼女の名前／あなたの名前ナシ）→ 「最初から、あなたのものではなかった」→ **赤フェード＋ラスト無音**、判例出典・免責・クレジット表示
