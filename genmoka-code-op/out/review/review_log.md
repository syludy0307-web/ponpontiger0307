## 1周目（全体を通した最初の確認）
- 【修正】音声が実行ごとに 1ULP（1.8e-7）ずれる → Chromium の多入力ノードの加算順が不定なため。
  OfflineAudioContext の処理は「1入力の直列チェーン」だけにし、ミックスは JS 側で固定順に加算 → バイト一致
- 【修正】赤胡麻の黒い毛先がほぼ見えない → 胡麻マスクを内側へ広げ、黒い毛先の毛を専用レイヤーで追加（リム光を抑制）
- 【修正】ヒーローショットの胸と前脚が白い塊（雪だるま状）→ 3/4顔リグの首パーツを外し、胸の白を縮小、首輪をヒーロー体に直接描画
- 【修正】カット5のモカが小さい → 0.36→0.41 倍
- 【修正】耳をさらに小さく・前傾に（秋田らしさ）

## 2周目（動き・文字・画質）
- 【修正】ゲンの鼻ひくっが弱い（約4px）→ 振幅を2倍強、鼻の穴の開き＋上唇の追従を追加
- 【確認】片耳の動き（バネ）、半目＋まばたき、呼吸
- 【修正】モカのまばたきで目の輪郭が残る「ゴーグル」状態 → 焼き込んだアイラインを廃止、下まぶたが上がって ⌒ で閉じる方式に変更
- 【確認】カット3：しっぽが先に見える→顔が上がる→前足→首かしげ→しっぽの先ぴくっ
- 【確認】カット4：しゃがみ（お尻ふり）→跳躍→頂点で紅葉をキャッチ（落葉の軌跡を前足位置へ補正）→落下→ゲンの前足にころん
- 【修正】筆文字の出を 0.25s→0.1s に（「0.0–3.0秒」に合わせる）
- 【修正】カット5の開始（ズーム1.13）で話数タイトルがモカに重なる → ズーム中心を下げて回避
- 【修正】スマホ縦で情報表示が切れる → コンパクト表記
- 【確認】バンディング：デコード後のフレームを高域強調／コントラスト伸長で確認
- 【修正】ラウドネス：AAC 化後に -16.5 LUFS → 映像と音声を分けてエンコードし、AAC 実測で残差補正 → -16.0 LUFS
