# 画像だけでどこまで動かせるか — テスト（動画生成AIなし）

動画生成AIを使わず、**静止画＋コード**だけで作った 16 秒のテスト動画です。

- 動画：`out/image_motion_test.mp4`（1920×1080 / 30fps / 16秒 / H.264 + AAC / -16 LUFS）
- 静止画：`out/review/`（コンタクトシート、各カットの静止画、自動中割りの比較 `interp_compare.jpg`）
- 本番は、あなたが用意した画像に差し替えます。このテストでは代わりに、著作権フリー（CC0）の秋田犬の写真と、パブリックドメインの連続写真（1887年）を使っています。

## 3つの方式と結果

| カット | 素材 | 動かしたもの | 評価 |
|---|---|---|---|
| ① 写真1枚だけ | 写真1枚 | 呼吸、うとうと（首のこっくり）、耳ぴくっ、鼻ひくひく、毛先と草の風、差し込む光、ほこりの粒、カメラの寄り＋奥行き | ◎ 写真の質感のまま自然に動く。動きは小さめ（数ピクセル〜数度） |
| ② 切り抜き1枚＋モーショングラフィックス | 写真1枚（切り抜き） | 頭の上下・首かしげ、口のハッハッ、しっぽ振り、耳、胸の上下、体の弾み（すべて曲の拍に同期）、背景・文字・紅葉・帯テロップ | ◎ Xの動画のような「切り抜き＋演出」の構成は画像1枚で作れる。ただし踊る（手足を大きく動かす）のは無理 |
| ③ ポーズ画像8枚をつなぐ | 連続したポーズ画像8枚 | 走る（ポーズの切り替え＝コマ送り） | ○ 大きな動きはポーズの数だけ画像が要る。アニメのコマ送り風になる |

**自動の中割り（オプティカルフロー）**は、ポーズの差が大きいと脚などが二重になります（`out/review/interp_compare.jpg`）。大きく動かすときは、中割りを自動で作るよりポーズ画像を増やすのが確実です。

## 仕組み

| 要素 | 実装 |
|---|---|
| 切り抜き | GrabCut（手で置いた前景・背景のヒント）→ 色の直線モデルで毛先の半透明を推定 → 縁の色を内側の毛色に置き換え → 芝の照り返しの緑を除去。すべて従来の画像処理で、生成AIは使っていない |
| 背景の穴埋め | 犬が動いて見える部分だけを、多段ぼかしの補間＋周囲の芝の模様で埋める |
| 動き（リグ） | 部位ごとのやわらかいマスク（頭・耳・鼻・あご・しっぽ・胸）に回転・拡大・移動を与え、画面の各画素を「カメラ⁻¹ → 変形⁻¹ → 元画像」で1回だけサンプリング（二重の再サンプリングなし） |
| 風 | 固定シードのノイズ場で、毛のふちと草だけを揺らす |
| 演出 | 光・ほこり・ブルーム・周辺減光、背景の円・リング・ストライプ・紅葉・帯テロップ・文字（Noto Sans JP / Yuji Syuku） |
| 音 | numpy で合成（前半はパッドと弦っぽい音、後半は 120 BPM のビート）。-16 LUFS に正規化 |
| 決定論 | 乱数はすべてシード固定。同じフレームは何度描いても同一（SHA-256 一致を確認） |

## 動かし方

```bash
pip install -r requirements.txt   # numpy / opencv-python-headless / Pillow（＋ ffmpeg）
python prep.py                    # フォント取得、切り抜き、背景の穴埋め → work/
python render.py --review         # 確認用の静止画 → out/review/
python render.py                  # 動画 → out/image_motion_test.mp4（4コアで約2分半）
python interp_compare.py          # 自動中割りの比較画像
```

クレジットは `CREDITS.md`。

## 自分の画像で動かす（グリーンバックの1枚から）

```bash
mkdir -p input && cp <あなたの画像>.png input/trio.png
python trio_render.py input/trio.png     # → out/private/trio_test.mp4（8秒）と確認用の静止画
```

- グリーンバックは色差キーで抜く（髪の毛の半透明も残す）→ 縁の色の置き換え → 緑かぶりの除去
- まばたきは「目を閉じた画像」がなくても、まぶたの皮膚・毛を目の上に下ろす変形で作る（`blink.py`）
- 部位ごとの動き（髪のゆれ、首、イヤリング、耳、鼻、子猫の首かしげ・ゆっくりまばたき）の位置は `trio_shot.py` に座標で書いてある。別の画像では座標を合わせ直す
- `input/` と `out/private/` は git 管理外（公開リポジトリにキャラ画像や動画が上がらないように）
