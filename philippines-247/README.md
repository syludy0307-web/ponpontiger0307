## セクション構成（音声同期）

1. フック（0-6.6秒）… 不穏な赤背景 → 「刑務所に入らない」赤スラム → 「現行法」金バッジ
2. 刑法247条（6.6-22.4秒）… 木槌＋条文カード → 現場のドアシーン → 「デスティエロ」金スラム＋立入禁止マップ → 檻が跳ね返る演出
3. 適用条件（22.4-38.2秒）… ハザード背景 → 条件①②チップ → ✖ホテルの前/✖事後 → 閉じるドア＋砂時計（翌日で反転）→ 「ただの〇人罪」赤スラム
4. 1987年の判例（38.2-48.6秒）… 判例カード → 「1時間後でも適用」金 → 巻き添えボヨン → 「そっちでは有罪」スタンプ
5. 結び（48.6-56秒）… 「廃止運動の対象」→ 静かに「誰もいない」
