# RA10175 4条a項1号 不正アクセス ショート（49.0秒 / 1080x1920 / 30fps）

「パスワードを盗み見た」— サイバー犯罪防止法の不正アクセス解説。シリーズ9本目。
**引っ張り型**：前半は白で押し切り、【3】で前提を反転させて赤を解禁する構成。

## 演出ルール（台本指定・厳守）

- **【1】【2】（〜14.55秒）は白のみ**。「盗み見た」に赤を当てない。前半で色を出すと落差が消える
- **【2】の白い札3枚は完全に同格**（同じサイズ・同じ入り方・同じ効果音 shutter・同じgain）。3枚目に強調を付けない
- 14.55-14.85 **黒0.3秒** ／ 同時に **BGM を1段変更**（-18.6dB → -14.6dB）
- 【3】頭 14.87秒に **RGBグリッチ1回**（この回で唯一）。ここから赤が解禁。プログレスバーも白→赤に変わる
- **赤フラッシュは42.30秒の1回だけ／低音のドンは44.35秒の1回だけ**
- BGM は 42.30-44.35 **完全無音**（赤フラッシュ→静寂→ドンで復帰）
- ボヨン（ツッコミ音）は不使用（gain 0）

## セクション構成

1. 【1】0-8.6秒 … スマホのロック画面。パスコード4桁が順に押されて光る（7-2-0-4）→ 覗き見の視線がシアンで寄る → 白フラッシュで解錠 → メッセージが上から下へスクロール。テロップは白のみ「盗み見た」「開けた」
2. 【2】8.6-14.55秒 … **白い札が1枚ずつ置かれる**（不安だった／浮気は本当だった／写真を撮って保存した）。3枚とも完全に同じ扱い
3. 黒0.3秒 … BGM 1段変更
4. 【3】14.85-23.75秒 … **RGBグリッチ**（色収差＋走査スライスずれ）→ 札が縮んで上に整列 → 赤×が順に落ちる（不安だった／浮気は本当だった）→ 中央に赤枠「権限があったか」。背景はフィリピン共和国紋章（BATAS AT BAYAN）
5. 【4】23.75-33.2秒 … **キーパッド4点の押下軌跡が光の線として残り → 鍵の形に立ち上がり → 鍵穴の手前で赤く染まる** ／「悪意」の札が要件リストから外れて落下 ／ **扉が観音開き＋「成立」の赤判子** ／ **保存写真が裏返り、裏面に ACCESS LOG（AUTH: NOT GRANTED / RESULT: ENTERED）が浮かぶ**（この回の一番の絵）
6. 【5】33.2-42.3秒 … 「サイバー犯罪防止法 / RA 10175」→ 4条a項1号 赤判子 → **刑のバーが伸びて 6年1日 → 12年 カウントアップ** → 罰金 ₱200,000〜
7. 【6】42.3-49.0秒 … 赤フラッシュ＋BGM無音 → 証拠写真に緑チェック（証拠は「あった」）→ **低音のドンで「法的に負ける」**（slam）→ 赤枠 RA10175 4条a項1号 → エンドカード
