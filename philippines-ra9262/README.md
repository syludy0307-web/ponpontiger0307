# RA9262ショート動画（58秒 / 1080x1920 / 30fps）

フィリピンRA9262（女性と子どもに対する暴力防止法）の解説ショート。
シリーズ3本目。今作から**実写写真の差し込み**に対応（Ken Burnsズーム＋シリーズ調トーン合成）。

## ビルド手順

```bash
node fetch_photos.cjs   # Wikimedia Commonsからライセンス安全な写真を取得（実行済み）
NODE_PATH=/opt/node22/lib/node_modules node capture.cjs   # → out/video_silent.mp4
node mix.cjs   # → out/philippines_ra9262_final.mp4 + philippines_ra9262_tiktok.mp4
```
