# ワールドミステリーch ／「夢の中で死ぬと現実でも死ぬ」説

動画収録用の HTML ビジュアル。古書を捲っていく形式で台本を進行します。
**16:9（1920×1080）固定**、そのまま画面収録すれば映像素材になります。

## 使い方

`index.html` をブラウザで開いて、画面をクリック → 本が開きます。
（そのままダブルクリックで開いても、ローカルサーバー経由でも動作します）

```bash
# サーバー経由で開く場合
npx http-server -p 8080 .   # → http://localhost:8080/
```

推奨は **Chrome / Edge** の全画面（`F`キー）。

### 画面サイズについて

ウィンドウがどんな比率でも、16:9 を保ったまま**常に中央にぴったり収まります**。
ウィンドウが 16:9 でないぶんは黒帯（レターボックス）になるので、収録範囲は黒帯の内側だけを切り取ってください。

HUDの右側に**いま表示されている実サイズ**（例 `1621×912`）が出ます。
これがちょうど `1920×1080` になるようウィンドウを調整すれば、**等倍・無劣化**で収録できます（数字が明るくなったら等倍）。

画面が 1920×1080 以上あるなら `Z`（原寸モード）で強制的に 1920×1080 に固定できます。
1920×1080 のディスプレイなら、全画面（`F`）にするだけで黒帯なしの等倍になります。

### 操作

| キー | 動作 |
|---|---|
| `Space` `→` | 次のページへ（3Dページめくり＋SE） |
| `←` | 前のページへ |
| `P` | 自動再生 / 一時停止 |
| `[` `]` | 再生速度 ×0.5 〜 ×2.0 |
| `I` | 目次（章ジャンプ） |
| `W` | ワイプ枠の切替：透明 → 黒 → グリーン → マゼンタ → カメラ |
| `C` | UI を全部隠す（**収録時はこれ**） |
| `M` | SE ミュート |
| `F` | 全画面 |
| `Z` | 画面に合わせる ⇄ 1920×1080 原寸 |
| `Home` / `End` | 最初 / 最後へ |

本の左半分クリックで戻る、右半分クリックで進む、でも操作できます。
マウスを 3 秒動かさないと UI は自動で消えます。

### 収録の手順

1. 全画面（`F`）→ `C` で UI を消す
2. `P` で自動再生を開始（台本の尺どおりに自動でめくれます）
3. 画面収録
4. ナレーションと BGM は編集で乗せる（このページは SE しか鳴りません）

自動再生は台本のタイムコードに合わせてあり、**全 41 見開き / 約 14分51秒**。
ナレーションと合わない場合は `[` `]` で速度を調整するか、`P` で止めて手動でめくってください。

### ワイプ枠（右下）

枠の中は**本当に切り抜かれています**（枠のリングだけを描画）。

- **透明** … 背景がそのまま透ける。編集ソフトで上にカメラ映像を重ねる用
- **グリーン / マゼンタ** … クロマキー用のベタ塗り（この時は反射エフェクトが自動で消えます）
- **黒** … 単色で塞ぐ
- **カメラ** … ブラウザのカメラをその場でプレビュー（確認用）

枠の下の「案内人」は**その場で書き換えられます**（クリックして入力）。

## 中身

- **背景** … 廃墟の実写＋ピラネージの銅版画を重ね、常時ゆっくりドリフト
- **埃** … canvas パーティクル 250 個。手前の大粒はボケ・奥は細かく、常時漂う
- **右上ロゴ** … 「ワールドミステリーch」がネオン管のように不規則に明滅＋たまにグリッチ
- **ページめくり** … `rotateY` の実 3D。表裏で別ページを持ち、影・落ち影・小口の厚みが進行に合わせて変化
- **SE** … `assets/se/page-turn.mp3` をめくるたびに再生（差し替えはこのファイルを上書きするだけ）

**OP（0:00〜0:40）は台本どおり除外**しています。冒頭は扉ページのみ、本編は第1章「誰も確認できない奇妙な説」から始まります。

## 画面に出す文章について

**ナレーション原稿は画面に出しません。** 喋る内容がそのまま出ていると読み聞かせになってしまうので、

- **右ページ** … 見出し＋要点だけの「資料」。用語（`レム睡眠` `扁桃体` `SUNDS` など）、数字、×／○の対比
- **左ページ** … 図版・図解・大きな引用

という役割分担にしてあります。左右で同じ文が出ないことは自動チェック済みです。

台本の全文は各ページの `say` に残してあり、**尺の配分にだけ使っています**（画面には出ません）。
そのため自動再生のタイミングは台本のタイムコードどおりのまま、画面の文字数だけが減っています。

## 手を入れる

`index.html` 一枚に全部入っています。

`CHAPTERS` 配列が全ページの中身です。1ページはこの形:

```js
{ left: P("図版に添える一言"),          // 左ページ
  say : ["ナレーション原稿…"],          // 画面に出ない。尺の配分にだけ使う
  head: "見出し",                       // 右ページ
  pts : ["要点",                        //   ・ふつうの要点
         {k:"用語", t:"説明"},          //   ・用語＋説明（枠つき）
         {c:"q",  t:"結論"}],           //   ・赤字の結論
  note: "小さい補足" }                  //   任意
```

- **左ページ** … `P()` 図版 / `Q()` 引用 / `F()` 図解 / `X()` 部分拡大
- **尺** … 各章の `sec`。章内は `say` の文字数比で自動配分されます
- **図版の差し替え** … `IMG` のパスを変えるだけ（`fit:"contain"` で全体表示）
- **レイアウト** … CSS 冒頭の `:root` 変数（本の位置・サイズ、ワイプの位置・サイズ）

要点を増やしすぎてページからはみ出しそうになると、間隔 → 級数 → 行間 の順に自動で詰まります。
