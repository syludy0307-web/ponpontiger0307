# ponpontiger0307

熊本地震とイオンモール熊本爆発｜判明していない20の論点
— YouTube 収録用のビジュアルブリーフ（16:9 / 1920x1080 想定）

`index.html` をブラウザで開くだけで動きます。ビルド不要・外部ライブラリなし。

---

## 全ページに入っているもの

| 要素 | 内容 |
|---|---|
| **ワイプスペース** | 画面**右下**に 16:9 の枠を常時確保。ここに自分のカメラ映像を後乗せする。本文は必ずこの枠を避けて組まれる |
| **常に動く参考イラスト** | 各ページ固有の SVG アニメーション（背景）＋ 画面上部を流れ続ける地震計ストリップ |
| **「イメージ」ボタン** | 左下。押すとそのページに紐づく**動く参考イラスト**が拡大表示され、補足情報と参考写真が出る |
| **追加情報** | 一般知識パネル・数値ファクト・注記を各ページに追加 |
| **写真** | Wikimedia Commons の実写（当該施設の平時写真／別事案の参考写真）。出所とライセンスを常に表示 |

## 操作

| キー | 動作 |
|---|---|
| `→` / `Space` / ホイール下 | 次のページ（**効果音が鳴る**） |
| `←` / ホイール上 | 前のページ（**効果音が鳴る**） |
| `I` またはボタン | イメージを開く／閉じる（**効果音が鳴る**） |
| `Esc` | イメージを閉じる |
| `W` | ワイプ枠の表示切替：ガイドあり → 枠なし → クロマキー(緑ベタ) |
| `D` | ワイプ枠をピンクで塗る（本文がかぶっていないかの確認用） |
| `M` | 効果音のミュート |
| `Home` / `End` | 最初 / 最後のページ |

画面下のナビゲーションボタンは、2.6 秒操作しないと自動的に消える（収録に映り込まないように）。
途中のページから開きたいときは URL に `#5` のように付ける。

## 効果音

| ファイル | 鳴るタイミング |
|---|---|
| `assets/se/se-page.mp3` | ページを送ったとき |
| `assets/se/se-image.mp3` | イメージボタンを押したとき（開くとき・閉じるとき） |

ブラウザの自動再生制限があるため、**最初に一度画面をクリック**すると鳴るようになる。
差し替えるときは同じファイル名で置き換える。

## ワイプ枠の使い方

収録するときは `W` キーで表示を切り替える。

- **ガイドあり**（初期状態）— 位置合わせ用。枠とコーナーマーカーが出る
- **枠なし** — 背景だけ。あとから編集ソフトでカメラ映像を重ねる場合はこれ
- **クロマキー** — 緑ベタ塗り。OBS などでキー抜きする場合はこれ

枠のサイズ・位置は `assets/css/deck.css` の `:root` にある `--wipe-w` / `--wipe-h` /
`--wipe-r` / `--wipe-b` で変えられる。本文の退避量（`--stage-clear` など）は
そこから自動計算されるので、**この4つだけ**いじれば全ページ追従する。

`D` キーでワイプ枠をピンクに塗ると、本文がかぶっていないか一目で確認できる。

## 内容を編集する

本文はすべて `assets/js/slides.js` の `SLIDES` 配列に入っている。HTML は触らなくていい。

```js
{
  kicker: '不明点 01',
  title: 'ガスは<br>どこから漏れた？',
  layout: 'split',            // 'split'（2カラム）か 'full'（1カラム）
  ambient: 'pipes',           // 背景で動くイラストの種類
  left:  [ /* ブロック */ ],
  right: [ /* ブロック */ ],  // layout:'full' のときは body: [...]
  source: '出典：…',
  image: {                    // イメージボタンの中身
    title: '配管のどこが壊れうるか',
    scene: 'pipes',
    caption: '…',
    side: [ /* ブロック */ ]
  }
}
```

使えるブロック：
`panel` / `list` / `quote` / `warning` / `note` / `facts` / `timeline` / `photo` / `slot` / `html`

ワイプ枠・常時アニメ・イメージボタン・フッターは `deck.js` が全ページに自動で付ける。
データ側に書き忘れても消えない。

### 情報の確度タグ

このデッキは「**確定していることと、まだ判明していないことを混ぜない**」ことを構成のルールにしている。
パネルには確度タグを付ける。

| タグ | 意味 | 色 |
|---|---|---|
| `confirmed` | 報道・公式発表で確認されている | 緑 |
| `unknown` | まだ判明していない・確認前 | 橙 |
| `hypo` | 仮説・可能性の列挙 | 水色 |
| `knowledge` | 今回の取材情報ではない、教科書的な一般知識 | 紫 |

`knowledge` は「ガスの性質」「法令の枠組み」「調査の手順」といった一般論のためのタグ。
今回の事故について新しい事実を推測で足すことはしない。

### 写真を差し替える

いま入っている写真は、すべて Wikimedia Commons の
**当該施設の平時写真**（緑バッジ）か**別の災害・別の事故の参考写真**（橙バッジ）。
この事故当日の報道写真は自由に使えるライセンスで存在しないため入れていない。

実写を入れる場合は、権利処理を済ませたうえで `assets/photos/` に置き、
`slides.js` の `slot` ブロックを `photo` ブロックに書き換える。
`slot` ブロックは、その差し込み位置を画面上に点線で示すためのもの。

### 動くイラストを足す

`assets/js/scenes.js` の `SCENES` にキーを追加すると、
`ambient`（背景・ラベルなし）と `image.scene`（拡大・ラベルあり）の両方で使える。

```js
SCENES.mykey = function (big) {
  var t = L(big);                 // big のときだけラベルを出すヘルパー
  return wrap('<circle …/>' + t(60, 100, 'ラベル', 15));
};
```

アニメーションは `deck.css` の `.an-pulse` / `.an-rise` / `.an-dash` などを
`class` に付けて、`style="--d:2s;--dl:.4s"` で長さと遅延を指定する。
