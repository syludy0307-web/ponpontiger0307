# 夜ラジ｜フィリピンパブ嬢 ／ SE 付き

いただいた kinetic HTML に効果音（SE）を足したものです。動きはそのまま、音だけ追加しています。

## どこで鳴るか

台本の中身ではなく、**HTML の属性**を見て音を出し分けています。手で1個ずつ指定しなくても、
既にある `data-in` / `data-hit` / `data-shake` がそのままトリガーになります。

| 鳴るタイミング | 判定 | スロット |
|---|---|---|
| **決めの一撃** | `data-hit` のインパクト（出現の200ms後） | `hit` |
| 強調テキスト | `data-in="slam" / "drop" / "glitch"`、`data-shake` | `emph` |
| 軽い強調 | `data-in="pop" / "zoom" / "neon"` | `pop` |
| タイプ表示 | `data-in="type"`（1文字ごと・52ms間隔） | `type` |
| 通常の行送り | それ以外（swipe / fly / slide / roll / wave / rise） | `line` |
| **ページ送り** | 章の切替（`goChapter`） | `page` |
| 最後のページ | 最終章の最後の行を出したとき | `end` |
| 戻る | `←` で1行戻す | `line`（音量45%） |

`data-hit` の行は、出現時に `emph`、200ms後のインパクトで `hit` の2段構えです。振りかぶって当たる感じになります。

## 自分の SE を使う

**方法1：ドラッグ＆ドロップ（ファイル名そのままでOK）**

1. ページで `S` キー → 右下に SE パネルが開く
2. 使いたい行に、SE フォルダから音声ファイルをドラッグして落とす
3. すぐ試聴されます。ブラウザに保存されるので、次に開いても残ります

`…` ボタンからファイル選択でも同じです。`×` で内蔵音に戻ります。

**方法2：`se` フォルダにまとめて置く**

この HTML と同じ場所の `se` フォルダに、この名前で入れてください。

```
se/line.mp3   se/pop.mp3   se/emph.mp3   se/type.mp3
se/hit.mp3    se/page.mp3  se/end.mp3
```

**置かなくても鳴ります。** 未設定のスロットは内蔵の合成音（WebAudio）が鳴るので、無音にはなりません。
パネルの右側に「内蔵音」か「読み込んだファイル名」が出るので、どれが差し替え済みか一目で分かります。

## 操作

もとの操作はそのままで、3つ足しています。

| キー | 動作 |
|---|---|
| `S` | SE パネルの開閉 |
| `M` | 消音 |
| パネルのスライダー | 全体音量 |

## 音量の初期値

各スロットの初期音量は `index.html` の `SE_SLOTS` にあります。うるさい／小さいときはここの数字だけ変えてください。

```js
var SE_SLOTS = [
  { key:"line", label:"行送り（通常）",           vol:0.40 },
  { key:"pop",  label:"軽い強調（pop/zoom/neon）", vol:0.55 },
  { key:"emph", label:"強調テキスト（slam/drop）", vol:0.70 },
  { key:"type", label:"タイプ表示（1文字ごと）",   vol:0.28 },
  { key:"hit",  label:"決めの一撃（インパクト）",   vol:1.00 },
  { key:"page", label:"ページ送り（章の切替）",     vol:0.80 },
  { key:"end",  label:"最後のページ",             vol:0.85 }
];
```

`type` は1文字ごとに鳴るので、短くて小さい音（タイプライターのカチッなど）が向いています。
26文字を超える行では26回で打ち止めにしています。

## 収録するとき

`S` パネルは録画に映るので、**`S` を押して閉じてから**録画を始めてください。
`G`（セーフエリア）`F`（全画面）`R`（最初に戻る）は元のままです。
