効果音（SE）の置き場所

このフォルダに mp3 を入れると、ページを開いたときに自動で読み込まれます。
ファイル名はこの7つです（拡張子は .mp3）。

  line.mp3   行送り（通常の1行表示）
  pop.mp3    軽い強調（data-in が pop / zoom / neon）
  emph.mp3   強調テキスト（data-in が slam / drop / glitch、data-shake）
  type.mp3   タイプ表示（1文字ごとに鳴る。短い音を推奨）
  hit.mp3    決めの一撃（data-hit のインパクト）
  page.mp3   ページ送り（章の切替）
  end.mp3    最後のページに到達したとき

置かなかったものは内蔵の合成音が鳴るので、無音にはなりません。

--------------------------------------------------------------------
ファイル名を変えたくない場合

ページ上で S キーを押すと SE パネルが開きます。
各行に音声ファイルをドラッグ＆ドロップすれば、名前のままその場で
割り当てられます（ブラウザに保存され、次回以降も残ります）。
