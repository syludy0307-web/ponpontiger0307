# assets/photos — 実写の置き場

報道写真など、自分で用意した画像をここに置く。

デッキ内で「差し替えスロット」として点線で表示されている箇所が差し込み先。
`assets/js/slides.js` の `slot(...)` ブロックを `photo` ブロックに書き換えると表示される。

```js
// 変更前
slot('配管・ガス設備まわりの報道写真', 'assets/photos/pipes.jpg')

// 変更後
{ t: 'photo', p: {
    src: 'assets/photos/pipes.jpg',
    kind: 'ref',                      // 'site'=当該施設 / 'ref'=参考 / 'slot'
    badge: '報道写真',
    title: '何を写しているかの説明',
    credit: '撮影者・媒体名 / 使用許諾の別'
} }
```

## 注意

- **権利処理を済ませた画像だけ**を置く。報道写真の多くは転載に許諾が必要。
- `credit` は必ず埋める。デッキは全ての写真に出所を表示する作りになっている。
- 今回の事故当日の写真ではないものを使う場合は、`badge` に
  「参考写真・別事案」のように明示する。何の写真かを取り違えさせないため。
